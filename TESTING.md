# Проверка Окон

Автоматические проверки запускаются одной командой:

```powershell
.\test.ps1
```

Скрипт собирает `dist\OknaTests.exe` из настоящих исходников (без окна и трея) и
проверяет то, что можно проверить без рабочего стола:

- направление трубочки для нижней, верхней, левой и правой панели задач;
- принудительное направление и «Авто»;
- геометрию скатывания для всех четырёх направлений: трубочка движется в нужную
  сторону, плоская часть только уменьшается, трубочка только растёт и не
  выходит за окно;
- попадание в панель задач и ограничение точки выхода её границами;
- маски исключений (`steam*`, `?`) и классы окон (`class:Progman`);
- правила для отдельных программ: старые и новые записи, маски, отключение
  изгиба/тряски/скатывания и эффект закрытия;
- наборы «Спокойно / Баланс / Желе / Экономно» и то, какой из них считается
  текущим;
- край панели задач по рабочей области монитора и высоту полос изгиба для
  разных разрешений;
- отличие нажатия на край окна от перетаскивания за заголовок;
- имя прокрученного журнала;
- режим «Экономно» и расширенный диапазон желейности (0–200);
- подпись горячей клавиши и миграцию старой настройки «скатывать сбоку»;
- решение об автозапуске: вторая запущенная копия не перехватывает запись;
- перенос настроек через `okna.ini` и отказ от чужих файлов.

Те же проверки выполняются в GitHub Actions на каждый коммит и перед релизом.

## Что проверить руками

Ниже — сценарии, которые автоматические тесты не покрывают. Отмечайте пункт,
только если он пройден на живой системе.

### Перетаскивание

- [ ] Окно Chrome/Electron отстаёт, изгибается и догоняет курсор.
- [ ] Содержимое не замирает: видео играет, проводник обновляется.
- [ ] `Shift` при перетаскивании — обычное поведение Windows и Aero Snap.
- [ ] Проводник не чернеет и не показывает полосы/артефакты.
- [ ] При отпускании окно мягко останавливается, без рывка.
- [ ] После отпускания края окно коротко пружинит по ширине и высоте и
      встаёт в новый размер.
- [ ] Нажатие на заголовок не принимается за перетаскивание границы.

### Трубочка

- [ ] Сворачивание кнопкой окна: картинка скатывается и улетает в кнопку окна
      на панели задач.
- [ ] Сворачивание из панели задач и по `Win+Down` тоже показывает трубочку.
- [ ] Направления «Вниз», «Вверх», «Влево», «Вправо» собирают окно с
      соответствующего края.
- [ ] «Авто» при нижней панели задач катится вниз, при верхней — вверх, при
      левой — влево, при правой — вправо.
- [ ] Трубочка попадает в кнопку именно этого окна, а не в центр панели.
- [ ] Если окно вернуть из панели задач, пока трубочка летит, анимация
      прекращается.
- [ ] Курсор, стоящий на кнопке сворачивания, не вызывает повторный снимок
      окна (в журнале нет повторного `Minimize armed` без движения).

### Закрытие

- [ ] «Осколки»: окно рассыпается от кнопки закрытия.
- [ ] «Сгорание»: огонь идёт снизу вверх, обугленный край, искры и дым.
- [ ] Telegram/Steam/Discord/WhatsApp/Slack при закрытии прячутся в трей:
      картинка скатывается в область уведомлений (медленные программы успевают
      за 0,5 секунды).
- [ ] «Без эффекта» закрывает окно обычно.
- [ ] Эффект для отдельной программы перекрывает общий (например, `chrome.exe`
      — осколки, все остальные — сгорание).
- [ ] «Свои правила для программы»: выключение изгиба, тряски или скатывания
      действует только на выбранную программу, остальные не меняются.
- [ ] Закрытие по `Alt+F4` работает так же, как кнопкой.

### Автопауза и исключения

- [ ] Полноэкранная игра или видео ставит эффекты на паузу; выход — снимает.
- [ ] Teams/Zoom/Discord/Slack впереди ставят паузу; переключение на другое
      окно — снимает.
- [ ] Питание от батареи ставит паузу, если включён соответствующий тумблер.
- [ ] Выключение анимаций в Windows (Параметры → Специальные возможности →
      Визуальные эффекты) ставит паузу, если включён «Уважать уменьшение
      движения».
- [ ] «Из запущенных…» показывает окна и добавляет программу или класс.
- [ ] Маска `steam*` исключает все окна Steam.
- [ ] `class:Progman` исключает рабочий стол.
- [ ] Исключённое окно перетаскивается и закрывается без эффектов.
- [ ] Значок в трее меняет цвет: пауза — янтарный, исключение — синий,
      выключено — серый.

### Настройки и трей

- [ ] Окно настроек открывается в ширину, двумя колонками; шапка, карточки и
      нижняя строка с кнопками видны целиком.
- [ ] При первом показе за запуск окно настроек мягко колышется само.
- [ ] Окно настроек можно потянуть за заголовок: оно изгибается и качается, как
      любое другое; `Shift` даёт обычное перетаскивание.
- [ ] Ползунок «Желейность» доходит до 200, подпись показывает число и слова;
      на 200 окна заметно вязче, чем на 70.
- [ ] На 200 при быстром перетаскивании край изогнутого окна остаётся плавным,
      без ступенек в несколько пикселей и без сплошных полос у края.
- [ ] После «Экономно» выбор «Желе» снова включает изгиб и тряску; если вместо
      этого потянуть ползунок, «Экономно» снимается и эффект возвращается.
- [ ] Левый клик по значку открывает настройки, правый — меню.
- [ ] В меню виден статус («работают», «пауза», причина).
- [ ] «Пауза на 30 минут» включает и снимает паузу, пункт показывает остаток.
- [ ] Быстрые переключатели железа, трубочки и эффекта закрытия работают и
      отражаются в открытом окне настроек.
- [ ] В меню трея подраздел «Режим» переключает «Спокойно / Баланс / Желе /
      Экономно», а галочка стоит на текущем наборе.
- [ ] Диалог «Правила для программы» сохраняет эффект закрытия и три
      переключателя; в списке видно «без изгиба», «без тряски», «без
      скатывания».
- [ ] На 2560×1440 и 4K изгиб остаётся плавным, без ступенек и сплошных полос.
- [ ] «Открыть журнал» открывает `%LOCALAPPDATA%\Okna\okna.log`.
- [ ] «Диагностика…» показывает версию, Windows, настройки, экраны, панели
      задач и хвост журнала; «Копировать» и «Сохранить…» работают.
- [ ] Смена горячей клавиши применяется сразу; занятая комбинация показывает
      предупреждение, а не молчит; `Backspace` выключает клавишу.
- [ ] «Экспорт…» создаёт `okna.ini`, «Импорт…» применяет его, «Сбросить»
      возвращает заводские значения.
- [ ] «Настройки рядом с программой» создаёт `okna.ini` рядом с `Okna.exe`;
      выключение возвращает настройки в реестр.
- [ ] Автозапуск включается и выключается, запись в
      `HKCU\...\Run\Okna` указывает на установленную копию.
- [ ] Запуск второй копии из другой папки не меняет автозапуск.
- [ ] Закрытие окна настроек прячет его в трей, а не завершает программу.

### Обновление

- [ ] «Проверить обновления…» сообщает «Обновлений нет» на последней версии.
- [ ] После установки обновления программа перезапускается и работает.
- [ ] Если новая версия не запускается, старая возвращается сама (проверяется
      подменой exe на заведомо нерабочий в тестовой папке).

## Несколько мониторов

Проверьте на конфигурации из двух мониторов (по возможности с разным DPI).

- [ ] Окно на втором мониторе перетаскивается с эффектом.
- [ ] Трубочка улетает в панель задач того монитора, где стоит окно, а не
      основного.
- [ ] При панели задач на каждом мониторе трубочка попадает в кнопку своего
      окна.
- [ ] «Авто» учитывает край панели задач именно этого монитора.
- [ ] Окно, перетащенное через границу мониторов, не прыгает и не меняет
      размер.
- [ ] Развёрнутое окно на втором мониторе покачивается в своих границах.
- [ ] Окно на мониторе с масштабом 150% не смещается относительно курсора.
- [ ] Снимок окна не захватывает часть соседнего монитора.
- [ ] Диагностика перечисляет оба экрана с их `bounds` и `work`.

## Смешанный DPI

- [ ] Основной монитор 100%, второй 150% (или наоборот): перетаскивание между
      ними не даёт скачка размера.
- [ ] Кнопка сворачивания на масштабированном мониторе определяется верно
      (трубочка стартует из окна, а не из пустоты).
- [ ] Окно настроек открывается целиком и прокручивается на 1366×768 и на
      1920×1080 при 150%.
- [ ] Шрифты и переключатели не разъезжаются при смене масштаба на лету.

## Windows 8.1

- [ ] Программа запускается (нужен .NET Framework 4.8).
- [ ] Перетаскивание работает; содержимое окна заморожено (нет Windows
      Graphics Capture) — это ожидаемо.
- [ ] Сворачивание в трубочку работает, направление «Авто» определяется.
- [ ] Если UI Automation не находит кнопку, трубочка уезжает в панель задач по
      геометрии — без исключения и без зависания.
- [ ] Осколки и сгорание работают.
- [ ] Автопауза: полноэкранный режим, удалённый рабочий стол, батарея.
- [ ] «Уменьшение движения» на 8.1 читается через
      `SPI_GETCLIENTAREAANIMATION`; при выключенных анимациях эффекты спят.
- [ ] Настройки, трей, автозапуск и обновление работают.

## Ограничения

- Многоэкранные и DPI-сценарии нельзя воспроизвести на машине разработки
  (один монитор, Windows 11), поэтому они проверяются по этому чек-листу.
- «Блокнот» Windows 11 (WinUI) не успевает отрисоваться для снимка; для него
  намеренно остаётся системная анимация.
- Закрытие через меню панели задач не отслеживается: снимок нужно сделать до
  исчезновения окна.
